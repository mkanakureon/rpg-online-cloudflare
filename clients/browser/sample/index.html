rpg-online ブラウザ SDK のサンプル

このページは http://127.0.0.1:5173/sample/ から開く（127.0.0.1:5173 から開く）。 file:// で開くとオリジンが null になり、Worker が CORS を返さないので動かない。

  1. Worker をローカルで起動する: npm run db:migrate:local && npm run dev（127.0.0.1:8787・APP_ENV=local）
  2. このページを出す: clients/browser/ で python3 -m http.server 5173 --bind 127.0.0.1
  3. ブラウザで http://127.0.0.1:5173/sample/ を開き、下のボタンを押す。終わったら 2 つのサーバーを止める。
