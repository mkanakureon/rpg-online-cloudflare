```text
gh issue list --state all --limit 100 --json number,title,state,labels,createdAt,closedAt,comments
node scripts/issue-run/doctor.mjs
node scripts/test.mjs
npm run typecheck
```

- 回数と費用: `.issue-run/logs/*/issue-<番号>-round<回>.json` の `total_cost_usd`・`duration_ms`・`session_id`・`permission_denials`。
- 確認コマンドの大きさ: `.issue-run/logs/*/issue-<番号>-check.mjs` の行数と `check(` の数。
- 未採用の改善: `.issue-run/logs/*/issue-<番号>-report.md` の「## 未採用の改善」の下の `- ` の行（「なし」を除く）。
- 押し返しの回数: `.issue-run/logs/*/issue-<番号>-stopblocks.txt`。

`.issue-run/` は追跡外なので、この数字はこの Mac の上でだけ出せる。
