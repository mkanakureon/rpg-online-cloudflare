# 費用アラートを作る（予算のアラート・使用量の通知）

この説明書は、自分の Cloudflare に Worker と D1 を置いた作者（`docs/guides/manuals/deploy.md` と同じ読み手）に向けた手順書です。
ゲームごとに Worker と D1 を自分のアカウントに置く形では、Cloudflare の料金と運用の責任は作者が持ちます（`docs/guides/decisions/operations-security.md` の 9 の配布責任）。
このリポジトリのサーバーは額を数えません（`docs/guides/working/analytics-design.md` §8）。費用の見張りは Cloudflare のダッシュボードで作ります。

> **先に読む:** 予算のアラートと使用量の通知は**知らせるだけで、Worker や D1 を止めません。** 知らせを受けたら、自分で使い方を見直すか止めます。
> **通知の宛先（メールアドレスなど）はファイルに書かない。** 宛先はダッシュボードにだけ入れ、このリポジトリ・`wrangler.jsonc`・Issue・チャットに書かないでください。

料金の額と無料の枠は、このリポジトリには書きません（変わるため）。見積もりの材料は `docs/guides/manuals/limits-and-costs.md` にあります。

## 前提

- 自分の Cloudflare のアカウントにダッシュボードから入れる。
- 予算のアラートは、従量の料金（Paid のプラン）のアカウントで使えると `analytics-design.md` §8 に控えた。Free のアカウントで使えるかは**要確認**です。
- 通知を受け取る宛先（メールなど）を決めてある。宛先は自分のアカウントの設定にだけ置く。

## 手順

### 1. 予算のアラートを作る

1. Cloudflare のダッシュボードで、請求（Billing）の中の「Billable Usage」（使った量と見込みの額）を開きます。
2. 予算のアラート（Budget alert）を作り、ひと月の予算の額と、知らせる割合を入れます。額は自分のゲームの遊ぶ人の数と `limits-and-costs.md` の見積もりから決めます。
3. 宛先はダッシュボードの画面で選びます（アカウントのメールなど）。**宛先をファイルに書かない。**

- 画面の名前・置き場・割合をいくつ持てるかは**要確認**です（Cloudflare の画面は変わります）。自分のダッシュボードで確かめてください。
- 予算を超えても Worker は止まりません。

### 2. 使用量の通知を作る

1. ダッシュボードの通知（Notifications）を開き、通知を足します。
2. Workers と D1 の使用量に関わる通知の種類を選びます（要求の数・D1 の読んだ行・書いた行・保存の量など）。
3. 宛先を選びます。メールのほか、Webhook などを選べる場合も、URL や宛先はダッシュボードにだけ置きます。

- 選べる通知の種類・しきい値の決め方・Free のプランで使えるかは**要確認**です。自分のダッシュボードの一覧で確かめてください。
- staging と production の Worker が同じアカウントにあるときは、通知の対象を production に絞れるかも見ます（**要確認**）。

### 3. 知らせを受けたときに見るもの

- Cloudflare のダッシュボードの Workers と D1 の使用量の画面（どの Worker・どの D1 が増えたか）。
- 管理の口の DAU（`GET /v1/admin/analytics/players`。P6 の後。`docs/guides/working/analytics-design.md` §5）で、遊ぶ人の数の増え方。
- 利用制限の回数（`src/core/rate-limit-policy.ts`）を超える要求が多くないか（429 の数）。

## 確かめ方

| 確かめ | どうするか |
| --- | --- |
| 予算のアラートがある | Billing の画面に、作った予算と割合が出る |
| 使用量の通知がある | Notifications の一覧に、作った通知が出る |
| 届く | ダッシュボードに試しの送信があれば使う（あるかは**要確認**）。無ければ、低い予算の額で一度作って届くことを見てから、本来の額に戻す |
| 宛先が漏れていない | `git grep -nE '[[:alnum:]._%+-]+@[[:alnum:]-]+[.][[:alpha:]]{2,}'`（メールの形）で、自分のフォークに宛先が入っていないことを見る |

## 困ったとき

| 起きたこと | 見るところ |
| --- | --- |
| 予算のアラートの画面が無い | アカウントのプラン（従量か）を見る。Free で使えるかは**要確認** |
| 通知が届かない | 宛先の綴りと迷惑メールのフォルダーを見る。ダッシュボードの通知の履歴があれば見る |
| 知らせが来たのに使用量が減らない | アラートは止めません。読み取りの多い口・掃除の Cron（`src/core/cleanup.ts`）が動いているかを見る |
| 宛先をファイルに書いてしまった | そのファイルから消してコミットし直す。push した後なら、宛先を変えることも考える |
